# Atividades Complementares (Opcional)

1. **Exercício 1:**  
   Modificar o jogo de adivinhação para limitar o número de tentativas e informar quando o usuário perder.

2. **Exercício 2:**  
   Criar uma função que utiliza `random.choice` para escolher uma dica aleatória (ex.: "quente", "morno", "frio") baseada na proximidade do palpite com o número secreto.

3. **Exercício 3:**  
   Dividir o código em diferentes módulos (por exemplo, `jogo.py`, `funcoes_auxiliares.py`) para praticar a modularização entre arquivos.

4. **Exercício 4:**  
   Adicionar um sistema de pontuação no jogo de adivinhação, onde cada palpite errado reduz a pontuação e o total é exibido ao final do jogo.

5. **Exercício 5:**  
   Criar um módulo separado com funções utilitárias, como validação de entrada e mensagens de erro, e integrá-lo ao jogo principal.

6. **Exercício 6:**  
   Implementar uma opção para que o usuário escolha jogar novamente ou sair do jogo, organizando essa funcionalidade em uma função específica.

7. **Exercício 7:**  
   Escrever testes unitários para as funções principais do jogo utilizando o módulo `unittest` do Python para garantir que todas funcionem corretamente.

8. **Exercício 8:**  
   Adicionar um recurso de registro (log) que armazene os palpites e os resultados em um arquivo de texto, e criar uma função para ler e exibir esse histórico.
