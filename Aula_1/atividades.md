# Sugestão de Atividade Prática de Fixação

## Instruções
Resolva as questões abaixo no Google Colab. Para cada exercício, crie uma célula de código e teste suas soluções.

### 1. Exiba uma mensagem na tela
Crie um programa que exiba a mensagem `"Bem-vindo ao mundo da programação Python!"`.  
**Dica:** Use o comando `print()`.

### 2. Realize uma soma simples
Escreva um programa que some os números `34` e `56` e exiba o resultado.

### 3. Resolva uma expressão matemática
Calcule e exiba o resultado da expressão:  
`(45 × 3) + (24 ÷ 6)`

### 4. Solicite entrada do usuário
Crie um programa que peça ao usuário para digitar seu nome e exiba a mensagem:  
`"Olá, [nome]!"`  
Substituindo `[nome]` pelo nome digitado.

### 5. Verifique par ou ímpar
Peça ao usuário para digitar um número e exiba se ele é **par** ou **ímpar**.

### 6. Calcule a área de um círculo
Crie um programa que calcule a área de um círculo com base no raio fornecido pelo usuário.

**Fórmula:**  
`Área = π × raio²`  
Considere `π = 3.14159`.

### 7. Determine o maior de dois números
Peça ao usuário para digitar dois números e exiba o maior deles.  
**Dica:** Use o comando `if`.

### 8. Calcule a média de três números
Crie um programa que peça ao usuário três números e calcule a média aritmética deles.

**Fórmula:**  
`Média = (soma dos números) / 3`

### 9. Converter Celsius para Fahrenheit
Crie um programa que converta uma temperatura em graus Celsius para Fahrenheit.

**Fórmula:**  
`Fahrenheit = (Celsius × 9 / 5) + 32`

### 10. Contagem regressiva
Escreva um programa que exiba uma contagem regressiva de `10` até `0` e, ao final, exiba a mensagem:  
`"Feliz Programação!"`
